# Summary
POC and MVP are not interchangeable, and confusing them sends a project down the wrong path before any code is written. A POC is a quick build proving something is technically possible, aimed at internal stakeholders rather than users, answering only 'can this be done' — as with the interactive concept produced to anchor Swinburne University's government grant tender. An MVP is the smallest version a real user gets genuine value from: a vertical slice with one feature working end to end, as with the focused information mini-site launched for Better Health Network while the full site was built behind it. Both are undermined by feature creep, so the test for any proposed addition is whether it is required to solve the core problem; if not, it goes on the backlog. Settling this before development starts is what a discovery phase is for.
